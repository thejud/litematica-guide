# Litematica Guide

A comprehensive guide to the [Litematica](https://modrinth.com/mod/litematica) schematic mod for Minecraft Java Edition (Fabric).

**Published at:** https://thejud.github.io/litematica-guide/

Covers all 9 tool modes, layer-by-layer building, the schematic verifier, material list, Easy Place, Realms compatibility, and a complete hotkey reference.
